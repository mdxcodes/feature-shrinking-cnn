# Streamlit frontend integration

Copy `app.py` into the root of your existing project (`/secondary/feature-shrinking-cnn/`).

## Install and run

```bash
source .venv/bin/activate
pip install streamlit streamlit-drawable-canvas matplotlib pillow
streamlit run app.py
```

Alternatively append these dependencies to the existing `requirements.txt`:

```text
streamlit>=1.40
streamlit-drawable-canvas>=0.9
matplotlib>=3.8
Pillow>=10
```

Do not replace the existing TensorFlow dependency or modify `model.py`.

## Features

1. Draw a handwritten digit using an interactive canvas.
2. Upload a handwritten digit image.
3. Run prediction using the saved CNN.
4. Show all ten softmax confidence scores.
5. Visualize all 16 first-convolution feature maps.
6. Visualize all 32 second-convolution feature maps.
7. Show training curves, evaluation metrics, confusion matrix, and sample predictions.
8. Explain the CNN architecture and spatial dimension reduction.

## Expected existing artifacts

- `models/best_mnist_cnn.keras` (preferred), or `models/final_mnist_cnn.keras`
- `results/evaluation_metrics.json`
- `results/training_history.json`
- Existing result PNGs generated by your training/evaluation pipeline.

The app preprocesses a single digit to 28×28 grayscale, normalizes it to [0,1], and runs local inference. For best results, use one centered digit with a clear background. No backend or cloud service is required.
